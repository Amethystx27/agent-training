# 实验说明指南

## 1. 文档用途

本指南说明 `experiment2_email_assistant` 中各文件夹和文件的内容、用途及相互关系，便于提交、审阅和复现。

实验包含两个部分：

- 基础实验：处理 ICCBDA 2027 的 A–F 六封邮件。
- 进阶实验：处理 AIIoT 2027 的 G 综合咨询邮件。

建议阅读顺序：

1. 阅读本指南了解目录结构。
2. 阅读 `README.md` 查看提交入口。
3. 阅读 `实验2总结.md` 和 `实验2进阶实验总结.md` 了解实验结果。
4. 查看 `outputs/` 中的逐封 JSON 和汇总草稿。
5. 如需复现，使用 `scripts/` 中的运行及验证脚本。

## 3. 根目录文件

| 文件 | 内容说明 |
|---|---|
| `.gitignore` | 忽略 Python 缓存和运行过程中可能重新生成的 `outputs/run_summary.json`、`outputs/validation_report.json`，防止临时输出进入仓库。 |
| `实验2 会议邮件智能回复助手.docx` | 原始实验要求，包含业务背景、意图类别、会议事实卡、邮件样本、Prompt 参考、进阶任务和提交要求。 |

## 4. 文件夹概览

| 文件夹 | 内容说明 |
|---|---|
| `email list/` | 保存原始英文邮件。A–F 属于基础实验，G 属于进阶实验。 |

| `docs/` | 保存基础实验的输入字段与输出格式说明。 |
| `prompts/` | 保存基础分析、基础回复以及进阶分类、提取和回复 Prompt。 |
| `schemas/` | 保存基础与进阶实验全部 JSON 输出的结构定义。 |
| `scripts/` | 保存基础与进阶实验的运行脚本和独立验证脚本。 |
| `outputs/` | 保存基础 A–F 和进阶 G 的最终分析、核验、回复及比较结果。 |
| `submission/` | 保存提交入口、实验总结、本指南和运行结果图。 |

## 7. `docs/` 格式说明

| 文件 | 内容说明 |
|---|---|
| `base_data_and_output_format.md` | 说明基础实验的数据范围、输入字段、分析格式、回复格式、事实核验状态、输出命名和检查项。 |

## 8. `prompts/` 模型提示词

### 8.1 基础实验

| 文件 | 内容说明 |
|---|---|
| `analysis_system.md` | 要求模型输出主意图、次级意图、全部问题、关键实体和人工审核判断。 |
| `reply_system.md` | 要求模型只依据事实卡生成英文草稿，并正确处理已知、未知、禁止回答和待人工审核事项。 |

### 8.2 进阶实验

| 文件 | 内容说明 |
|---|---|
| `advanced_single_label.md` | 要求只返回一个主导意图，用于观察复杂邮件中的业务意图漏检。 |
| `advanced_multi_label.md` | 要求完整返回统一类别和业务意图，发票请求映射为 `payment_inquiry`，业务层使用 `invoice_request`。 |
| `advanced_extraction.md` | 要求提取 10 个独立问题以及注册、住宿、发票相关实体和语言问题。 |
| `advanced_reply.md` | 要求分别生成 Formal、Concise、Friendly 三种英文草稿，并保持事实和未知项一致。 |

## 10. `scripts/` 源代码

| 文件 | 内容说明 |
|---|---|
| `run_base_experiment.py` | 基础实验主脚本，逐封调用模型处理 A–F，执行事实核验并生成回复。 |
| `validate_outputs.py` | 基础实验独立验证脚本，检查字段、意图、问题覆盖、事实核验和审核一致性。 |
| `run_advanced_experiment.py` | 进阶实验主脚本，执行单标签、多标签、信息提取、事实核验和三风格回复。 |
| `validate_advanced_outputs.py` | 进阶实验独立验证脚本，检查分类覆盖率、10 个问题、三风格一致性和事实边界。 |

## 11. `outputs/` 实验结果

### 11.1 基础结果汇总

| 文件 | 内容说明 |
|---|---|
| `draft_replies.md` | A–F 六封英文回复草稿、主题、人工审核标记和审核理由汇总。 |
| `fact_audit_summary.md` | 基础实验全部 10 个问题的核验状态、事实依据和人工审核判断。 |

### 11.2 基础逐封结果

每封邮件包含分析、事实核验和回复三个 JSON：

| 邮件 | 分析结果 | 事实核验结果 | 英文回复结果 |
|---|---|---|---|
| A | `email_a_analysis.json`：注册咨询和投稿截止日期 | `email_a_fact_audit.json`：费用和截止日期均受事实卡支持 | `email_a_reply.json`：确认 USD 350 和 February 15, 2027 |
| B | `email_b_analysis.json`：录用状态查询 | `email_b_fact_audit.json`：个人录用结果禁止通过邮件披露 | `email_b_reply.json`：引导查询投稿系统并标记人工审核 |
| C | `email_c_analysis.json`：付款确认和发票两个问题 | `email_c_fact_audit.json`：付款状态禁止确认，发票政策未知 | `email_c_reply.json`：不确认付款，发票请求转人工 |
| D | `email_d_analysis.json`：酒店推荐和机场交通 | `email_d_fact_audit.json`：住宿和交通信息均未知 | `email_d_reply.json`：说明住宿未公布、交通信息未提供 |
| E | `email_e_analysis.json`：退款资格和处理时间 | `email_e_fact_audit.json`：退款政策未提供，退款事项禁止承诺 | `email_e_reply.json`：不承诺退款和时限，并标记人工审核 |
| F | `email_f_analysis.json`：投稿上传故障 | `email_f_fact_audit.json`：通过故障信息收集流程处理 | `email_f_reply.json`：要求错误截图、投稿编号、浏览器和文件信息 |

## 13. 复现命令

在 `experiment2_email_assistant` 目录执行：

```powershell
python -B scripts/run_base_experiment.py
python -B scripts/validate_outputs.py
python -B scripts/run_advanced_experiment.py
python -B scripts/validate_advanced_outputs.py
```

运行脚本从上一级 `week1_llm_lab/.env` 读取 `OPENAI_API_KEY`、`OPENAI_BASE_URL` 和 `MODEL_NAME`。密钥只保存在内存中，不复制到实验目录。

## 14. 提交边界

- 基础实验使用 ICCBDA 2027 事实卡，进阶实验使用 AIIoT 2027 事实卡，两套事实不得混用。
- 所有回复均为草稿，不连接邮件发送服务。
- AIIoT 2027 发票请求需要人工审核。
- 原始邮件、数据、Prompt、Schema、源代码、结果和总结均属于提交内容。
