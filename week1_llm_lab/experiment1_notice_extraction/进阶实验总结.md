# 实验1进阶任务：AIIoT 2027 多类别多阶段注册信息提取

## 一、实验目的

本进阶任务基于 AIIoT 2027 征稿及注册通知，验证大语言模型能否完成以下工作：

- 提取会议名称、日期、地点和主题。
- 区分全文投稿、录用通知、最终论文提交和早鸟注册截止日期。
- 提取普通作者、学生作者和非作者参会者三类注册费用。
- 为每个类别分别提取早鸟价和普通价，共六种组合。
- 提取学生资格、证明材料、注册条件、费用包含服务和排除支出。
- 通过程序验证类别、阶段、金额、币种和日期之间的关系。

## 二、输入与环境

进阶输入保存在 `notice_d.txt`，来自实验 Word 文档中的 AIIoT 2027 通知。

运行环境与基础实验一致：

- Windows 10.0.26200。
- Python 3.12.10。
- `openai 3.46.0`。
- `python-dotenv 1.2.4`。
- `pydantic 2.14.3`。
- `temperature=0.1`。

入口程序为 `advanced_extract.py`，Prompt 位于 `advanced_prompts.py`，数据模型位于 `advanced_schemas.py`。

## 三、进阶数据模型

### 会议和日期

模型要求提取：

- 会议简称和完整名称。
- 会议开始和结束日期。
- 举办地点和主题。
- 全文投稿截止日期。
- 录用通知日期。
- 最终论文提交日期。
- 早鸟注册截止日期。

日期使用真实 `date` 类型校验，并检查投稿、录用、最终论文、会议开始之间的顺序。

### 注册费用矩阵

`registration_fees` 中每一项包含：

- `category`：`regular_author`、`student_author` 或 `non_author_participant`。
- `stage`：`early_bird` 或 `regular`。
- `amount`：正数金额。
- `currency`：三位大写币种代码。
- `discount_deadline`：早鸟项对应早鸟截止日期，普通项为 `null`。

程序要求六种类别和阶段组合恰好完整，且：

- 不允许缺少或重复组合。
- 所有费用使用相同币种。
- 每个类别的早鸟价低于普通价。
- 每项早鸟价的截止日期等于顶层早鸟截止日期。
- 普通价不能携带早鸟优惠截止日期。

### 注册政策

`registration_policy` 包含：

- `student_eligibility`：学生注册资格。
- `student_proof`：学生身份证明材料数组。
- `registration_conditions`：论文注册和早鸟付款条件。
- `included_services`：注册费用包含的服务。
- `excluded_expenses`：住宿、交通等不包含的支出。

## 四、进阶 Prompt 设计

### 进阶 Prompt V1

V1 使用简洁字段说明，要求：

- 只使用通知原文。
- 输出完整会议字段和注册政策。
- 费用矩阵必须覆盖三个类别和两个阶段。
- 日期使用 `YYYY-MM-DD`。
- 早鸟费用填写优惠截止日期，普通费用为 `null`。

第一次实际运行中，V1 输出的其他字段和六项费用均正确，但将 `student_proof` 写成了一个字符串。严格模型拒绝该结果。随后在 V1 中明确要求 `student_proof`、`registration_conditions`、`included_services` 和 `excluded_expenses` 必须为字符串数组，没有放宽校验规则。重新运行后 V1 通过。

### 进阶 Prompt V2

V2 提供更完整的业务约束：

- 分别定义会议日期和四个重要日期。
- 明确列出 3 × 2 的六个费用组合。
- 说明早鸟价、普通价与截止日期的对应关系。
- 明确费用金额和币种类型。
- 明确注册政策的五类字段。
- 特别提醒住宿和交通属于排除项，不能写进费用包含服务。

V2 首次运行即通过严格校验。

两版最终结果均正确提取：

- 会议日期：2027-06-18 至 2027-06-20。
- 投稿截止：2027-03-15。
- 录用通知：2027-04-20。
- 最终论文提交：2027-05-10。
- 早鸟注册截止：2027-05-01。

### 六项注册费用

两版最终结果均正确输出：

|---|---|---:|---|---|
| 普通作者 | 早鸟 | 400 | USD | 2027-05-01 |
| 普通作者 | 普通 | 500 | USD | null |
| 学生作者 | 早鸟 | 280 | USD | 2027-05-01 |

### 注册政策

两版均提取出：

- 学生价只适用于具有有效全日制学生身份的参与者。
- 证明材料为有效学生证或正式在读证明。
- 每篇录用论文至少需要一项完整注册。
- 早鸟优惠要求 2027-05-01 前成功付款。
- 费用包含技术会议、会议资料、茶歇和午餐。
- 住宿和交通费用不包含在注册费中。

## 七、V1 与 V2 对比

V1 的首次失败说明较简短的 Prompt 容易遗漏数组类型约束。明确补充后，V1 也能完成全部提取，且费用矩阵与 V2 一致。

V2 的首次运行即成功，主要优势是：

- 六个费用组合写得更明确。
- 日期字段职责更清晰。
- 政策字段的数组类型更清楚。
- 包含服务和排除费用有单独的提醒。

由于两版各只有一次最终运行，样本也只有一个，不能据此宣称 V2 的总体准确率高于 V1。目前只能确认 V2 对结构化约束的表达更完整，首次运行的稳定性更好。

## 八、当前局限

- 只有一个进阶会议通知。
- V1 和 V2 最终各运行一次，没有统计多次运行波动。
- 没有标准答案，不能计算严格语义准确率。
- 政策文本允许不同措辞，程序只能校验字段类型和完整性，不能完全判断语义等价。
- 当前收费矩阵固定为基础要求的三类参会者 × 两个阶段，后续可以扩展更多类别和阶段。
- 截图由真实运行保存的原始响应和 JSON 渲染生成，不是实时桌面窗口截图。

## 九、改进方向

- 增加更多包含不同币种、收费阶段和政策表达方式的会议通知。
- 对政策字段增加去重和语义一致性检查。
- 记录模型名称、请求耗时和运行状态。
- 在获得明确参考标注后增加语义准确率评估。
- 增加多轮重复运行，比较 V1 和 V2 的稳定性和错误分布。

## 十、结论

AIIoT 2027 进阶任务已经完成。最终保存的两版结果均通过严格模型校验，完整提取三类参会者的早鸟价和普通价共六项费用，并正确提取早鸟截止日期、学生资格、证明材料、注册条件、包含服务和排除支出。首次 V1 的类型错误通过明确 Prompt 约束解决，没有关闭或放宽严格校验。
