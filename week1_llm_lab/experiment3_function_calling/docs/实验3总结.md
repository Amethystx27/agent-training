# 实验3：会议时间查询工具（Function Calling）

## 1. 实验概述

本实验实现了一个基于大语言模型和本地 Python 工具的会议时间查询
Agent。模型根据用户问题选择工具，程序通过白名单执行工具，随后将
结构化结果返回给模型，由模型生成最终自然语言回答。

基础实验实现了：

- 当前时间查询；
- 日期差值计算；
- 模拟会议截止日期查询；
- IANA 时区转换；
- 单工具和多工具连续调用；
- 工具调用日志和错误处理。

## 3. 系统架构

```text
用户问题
  ↓
System Prompt + 工具 Schema
  ↓
大语言模型
  ↓ 返回 tool_calls
工具白名单调度器
  ↓ 参数解析与 JSON Schema 校验
本地 Python 工具
  ↓ 结构化结果或错误
以 tool message 回传 tool_call_id
  ↓
大语言模型继续选择工具或生成最终答案
  ↓
JSONL 调用日志
```

Agent 最多执行 6 个模型/工具轮次，防止模型无限重复调用。

## 5. 工具定义

| 工具 | 参数 | 返回内容 |
| --- | --- | --- |
| `get_current_time` | `timezone` | 带时区偏移的当前时间和格式化时间 |
| `days_until` | `target_date` | 今天、目标日期和剩余天数 |
| `get_conference_deadline` | `conference_name` | 截止日期和会议日期 |
| `convert_timezone` | `local_datetime`, `source_timezone`, `target_timezone` | 来源时间、目标时间和 UTC 偏移 |

所有工具结果均可转换为 JSON。错误结果使用 `ok: false`、
`error_code` 和 `error` 三个字段。

## 6. System Prompt

系统会在运行时注入当前日期，实际 Prompt 为：

```text
你是一个会议和时间助手。今天是 2026-11-13，用户默认参考时区是
Asia/Shanghai。

规则：
1. 查询准确当前时间、日期差值、会议截止日期或进行时区转换时，必须调用工具。
2. 不得编造会议信息。工具返回错误时，最终回答必须如实说明。
3. 未明确指定关键城市、日期或会议名称时，应先询问用户。
4. 只能使用提供的工具，不得假设工具已经执行。
5. 用户可以使用中文或英文提问。
```

当前日期不是固定写在代码中的，而是在每次 Agent 运行时生成。

## 7. Function Calling 流程

1. 将 System Prompt、用户问题和四个工具 Schema 发送给模型。
2. 模型返回 `tool_calls`，其中包含工具名称、JSON 参数和调用 ID。
3. 调度器确认工具在白名单内，并校验必填参数、参数类型和多余参数。
4. 程序执行对应 Python 函数。
5. 使用原始 `tool_call_id` 将 JSON 结果作为 tool message 回传模型。
6. 模型根据结果继续调用其他工具，或返回最终答案。
7. 日志记录模型轮次、工具参数、结果、耗时和最终回答。

调度器不允许模型执行 `eval`、`exec` 或任意生成的 Python 代码。

## 9. 调用日志

每次 Agent 运行生成一个独立的 `.jsonl` 文件。日志包含以下事件：

- `run_start`：用户问题、模型名称和开始时间；
- `model_request`：模型调用轮次和消息数量；
- `model_response`：结束原因、回答内容和工具调用；
- `tool_call`：调用顺序、工具名、参数、耗时、状态和结果；
- `runtime_error`：未预期的运行异常；
- `run_end`：最终回答、总轮数、工具次数和总耗时。

日志仅记录运行所需信息，不包含 API Key。

## 10. 异常处理

当前实现处理了以下错误：

- 未知工具：`UNKNOWN_TOOL`；
- 非法 JSON：`INVALID_JSON`；
- 参数缺失、类型错误或多余参数：`INVALID_ARGUMENTS`；
- 无效 IANA 时区：`INVALID_TIMEZONE`；
- 非法日期：`INVALID_DATE`；
- 无效时间：`INVALID_DATETIME`；
- 不存在的会议：`CONFERENCE_NOT_FOUND`；
- 夏令时期间不存在的本地时间：`NON_EXISTENT_LOCAL_TIME`；
- 夏令时期间有歧义的本地时间：`AMBIGUOUS_LOCAL_TIME`；
- 超过最大工具调用轮数：`MAX_TOOL_ROUNDS`。

Q6 证明工具错误会回传到模型，最终回答不会编造截止日期。

## 12. 已知限制

- 基础版会议数据只有 `ICCBDA 2027`，尚未建立完整 CSV 会议数据库。
- 城市名称到 IANA 时区的完整中英文映射属于进阶实验。
- 当前模型接口不支持强制 `tool_choice`，因此使用 `auto`。
- 当前 Base URL 为 HTTP，仅适合课程提供的可信实验环境。
- 日期工具使用运行机器的本地日历日期；System Prompt 的默认参考时区为
  `Asia/Shanghai`。
