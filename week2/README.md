# 第二周 RAG 企业知识库开发教学资料包
适用：8名计算机本科四年级学生；1周12–16小时。
所有会议、联系人、地点、费用均为教学虚构；example.org域名仅示例，不访问、不付款。

## 发放边界
学生：学生版指导书、学生资料、代码框架。教师：完整包，教师资料严禁放入学生知识库。
会议材料共8份DOCX；其中部分另供PDF替换，入库时同一编号只保留一个版本，保证8个逻辑文档。

## 建议项目结构
week02-rag/
  data/raw/         # 只放8份会议资料，PDF与DOCX同编号二选一
  src/rag.py        # 从代码框架复制，完成TODO
  data/chunks.jsonl # 含source和定位
  index/            # 本地持久化，不加载他人不可信索引
  results/          # 原始响应、检索与逐题评价
  report.md
  requirements-lock.txt
  .env              # 不提交

## 使用顺序
阅读指导书→配置环境与模型→复制8份会议资料→解析/切分/入库→检索→RAG→引用与拒答→28题评估→同伴互测→提交。
代码框架是有意留空的教学任务，不是可直接运行的成品系统。依赖需教师预跑并冻结；真实模型调用由教师配置验证，不在资料制作阶段声称已验证。
标准答案使用fact_id如02-1，表示02文件第1节；PDF以实际渲染页码为准，DOCX使用标题/段落范围。
