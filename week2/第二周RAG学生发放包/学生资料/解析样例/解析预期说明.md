# 解析样例说明

## 资料边界

本目录中的文件只用于测试文档解析能力，不属于正式会议知识库。

- 不要把样例文件默认复制到`data/raw/`。
- 不要把样例中的虚构会议、日期和费用加入正式28题答案。
- 如需测试完整入库链路，请使用单独的临时目录和临时索引。

## 表格解析样例

文件：

```text
表格解析样例.docx
```

预期识别结果：

- 文档标题：`教学会议文档解析样例`
- 标题/章节：
  - `1. 会议日程表`
  - `2. 注册费用样例表`
- Word表格数量：2

第一张表字段：

```text
日期、时间、环节、地点
```

第二张表字段：

```text
人员身份、早鸟费用、常规费用、到账条件、备注
```

检查点：

1. 两张表格均应产生非空文本。
2. 表头应被保留，不能只读取数据行。
3. 第二张表最后一行的“备注”为空，解析器不应因此丢弃整行。
4. DOCX定位应使用真实段落范围，不伪造页码。

## PDF解析样例

文件：

```text
PDF解析样例.pdf
```

预期识别结果：

- 物理页数：2
- 第1页标题：`PDF逐页解析样例（第1页）`
- 第2页标题：`PDF逐页解析样例（第2页）`
- 两页均包含可复制文本

建议分别保存：

```text
source
page: 1或2
locator_type: page
```

检查点：

1. 两页都能通过`pypdf`的`extract_text()`得到非空文本。
2. 页码从1开始。
3. 不应把物理页码记录成0。
4. 本样例不是扫描件，不需要OCR。

## 推荐验证方式

使用学生自己的`load_documents(path)`分别读取：

```text
学生资料/解析样例/表格解析样例.docx
学生资料/解析样例/PDF解析样例.pdf
```

记录文件数、章节数、表格数、页数、空文本数和提取文本样例，但不要覆盖正式8份会议资料的解析统计。
