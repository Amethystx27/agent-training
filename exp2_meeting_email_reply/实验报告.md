# 实验2：会议邮件智能回复助手 — 实验报告

> 基础实验（不含进阶挑战）。完整源代码、Prompt、测试输入输出见 `main.py` 与 `results.json`。

## 一、实验目的

为国际会议组织方开发一个英文邮件智能回复助手：
1. 读取英文会议咨询邮件（主题 / 发件人 / 正文）；
2. 调用大模型识别**主意图 + 次级意图**，提取用户问题、身份、论文标题等关键信息；
3. 依据**会议事实卡**（唯一可信依据）判断哪些问题可自动回答、哪些必须**人工审核**；
4. 生成英文回复草稿（对需人工审核的邮件标注 `[HUMAN REVIEW REQUIRED]` 并说明理由）；
5. 对邮件 A–F 逐一测试，保存分析结果 + 回复草稿。

## 二、运行环境

- Python 3.11（虚拟环境 `.venv`）
- `openai`（兼容接口）、`python-dotenv`、`pydantic`
- 模型：`deepseek-flash`，API Base 由 `.env` 中的 `API_BASE` 指定

运行方式：
```bash
# 真实调用 API（需要 .env）
python main.py --all
python main.py --email emails/email_A.txt

# 离线演示（不依赖网络，使用内置预设与事实卡规则）
python main.py --all --mock
```

## 三、会议事实卡（唯一可信依据）

| 项目 | 模拟官方信息 |
|------|--------------|
| 会议名称 | ICCBDA 2027 |
| 会议日期 | May 21–23, 2027 |
| 地点 | Xihua University, Chengdu, China |
| 全文投稿截止日期 | February 15, 2027 |
| 学生作者注册费 | USD 350 |
| 普通作者注册费 | USD 450 |
| 听众注册费 | USD 180 |
| 住宿信息 | 尚未公布，请关注会议官方通知 |
| 录用结果 | 只能通过投稿系统查询；邮件中不提供个人录用结论 |
| 退款政策 | 未提供正式政策，必须转人工确认 |
| 联系邮箱 | iccbda2027@example.org |

**关键约束**：模型只能依据事实卡回复，未提供的信息不得编造。退款、付款争议、录用结果、作者信息变更默认人工审核。

## 四、系统实现

### 1. 文件结构
```
exp2_meeting_email_reply/
├── main.py              # 主程序：分析 + 回复生成 + Pydantic 校验 + 离线 mock
├── requirements.txt
├── .env.example
├── emails/              # 邮件样本 A–F（原始英文邮件）
│   ├── email_A.txt ... email_F.txt
└── results.json        # 测试输出（分析 + 回复草稿）
```

### 2. 意图类别与人工审核规则
意图共 9 类：`registration_inquiry`、`submission_deadline`、`acceptance_inquiry`、`payment_inquiry`、`accommodation_inquiry`、`certificate_request`、`paper_update_request`、`technical_issue`、`other`。

必须人工审核（`requires_human_review = true`）：`acceptance_inquiry`（录用结果）、`payment_inquiry`（付款 / 退款 / 发票）、`paper_update_request`（作者信息变更）。

### 3. 处理流程
```
原始邮件文本
   │
   ▼
[分析 Prompt] ──► 大模型 ──► JSON ──► Pydantic(EmailAnalysis) 校验
   │                                               │
   │                                               ▼
   │                         依据事实卡 + 意图规则 判断 requires_human_review
   ▼
[回复 Prompt] ──► 大模型 ──► JSON ──► Pydantic(ReplyDraft) 校验
   │
   ▼
英文回复草稿（含 [HUMAN REVIEW REQUIRED] 标记）
```

### 4. 校验
- 分析结果与回复草稿均通过 Pydantic 模型（`EmailAnalysis` / `ReplyDraft`）做字段级校验，缺失或类型不符会立即报错，避免脏数据向下游传递。
- 离线 `--mock` 模式由内置预设分析与事实卡规则生成回复，保证在无网络时也能演示完整闭环。

## 五、测试结果（真实 API 输出摘要）

| 邮件 | 主意图 | 次级意图 | 人工审核 | 回复要点 |
|------|--------|----------|----------|----------|
| A | registration_inquiry | submission_deadline | 否 | 确认学生作者费 USD 350；投稿截止 2027-02-15 |
| B | acceptance_inquiry | — | **是** | 录用结果只能经投稿系统查询，标注 `[HUMAN REVIEW REQUIRED]` |
| C | payment_inquiry | — | **是** | 不声称已查到付款；转秘书处核实付款与发票，标注 `[HUMAN REVIEW REQUIRED]` |
| D | accommodation_inquiry | other | 否 | 住宿信息尚未公布，不推荐虚构酒店；建议联系秘书处 |
| E | payment_inquiry（退款） | — | **是** | 不承诺退款或处理时限，转人工确认，标注 `[HUMAN REVIEW REQUIRED]` |
| F | technical_issue | — | 否 | 引导提供错误截图、投稿编号、浏览器版本 |

**回复草稿示例（邮件 A）**
```

registration fee for student authors is USD 350.

The full paper submission deadline is February 15, 2027.

If you have any further questions, please contact the conference secretariat at
iccbda2027@example.org.

Best regards,
Conference Secretariat
ICCBDA 2027
```

**需人工审核示例（邮件 B）**
```
Dear Maria Chen,

... Acceptance results can only be checked through the submission system. ...

[HUMAN REVIEW REQUIRED]

Best regards,
ICCBDA 2027 Organizing Committee
```

## 六、错误与异常处理

- **信息缺失**：事实卡未提供的字段（如住宿、退款政策）一律返回「目前无法确认 / 尚未公布」，并引导联系秘书处，绝不编造。
- **高风险事项**：退款、付款状态、录用结果、作者信息变更被强制标记为人工审核，避免模型自动承诺。
- **输出合法性**：通过 `response_format=json_object` + Pydantic 双重保障，确保模型输出可被程序解析。

## 七、实验总结

本实验实现了「意图识别 → 信息提取 → 事实核验 → 回复生成」的会议邮件处理闭环。通过会议事实卡约束与人工审核标记，有效防止了大模型在缺少官方信息时「幻觉编造」。测试表明：对可回答类邮件（A、D、F）能准确引用事实卡；对高风险类邮件（B、C、E）能正确触发人工审核流程。
